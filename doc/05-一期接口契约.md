# 燕云十六声 · 百业组队平台 一期接口契约

> 版本：v1.1；日期：2026-10-13；状态：一期核心 60 个 HTTP 操作已实现，OpenAPI 响应类型已生成并供前端使用。QQ 与首次绑定的 4 个操作按用户要求暂停，表内相应内容为后续范围。实际交付和验收边界见《06-后端开发进度》。

## 1. 共同约定

- HTTP 路径统一加 `/api/v1`；SignalR 使用独立 `/hubs/notifications`。表中路径省略 HTTP 前缀。
- JSON 使用 snake_case；ID 为 UUID 字符串，version 为可安全表示的非负整数（数据库 bigint；超出 JavaScript 安全整数范围前升级为字符串契约）。时间为带时区 ISO 8601，响应 UTC `Z`，周边界为 Asia/Shanghai。
- 成功统一 `{ data: T, error: null }`，失败 `{ data: null, error: { code, message, details, trace_id } }`。创建业务资源返回 201，其余成功 200；QQ 跳转为 302，不套 JSON。DELETE 不要求请求体。
- 一般查询/写入使用 Bearer，业务要求账号存在、active 且已验证邮箱；`GET /me`、首次绑定和本人注销允许待绑定账号。注册/密码登录/刷新/退出按后端方案校验 Origin/CSRF；绑定、注销同样带 Bearer + CSRF。
- 未知写入字段拒绝为 VALIDATION_FAILED，禁止绑定客户端 user_id、created_by、status 等未列入请求的字段。PATCH 未出现的字段不修改，显式 null 只允许该字段可空时清除；任何 PATCH 至少包含一个可修改字段。
- 本人归属从 sub 获取；profile_id 反查账号；嵌套路径校验实际资源所属百业。UI 的 can_* 仅用于体验，写入必须重新鉴权。
- 页码分页 `page=1, page_size=20`，page>=1，page_size=1..100；返回 `Page<T>={items:T[],page,page_size,total}`。游标分页 `limit=20`，范围 1..100，返回 `CursorPage<T>={items:T[],next_cursor:string|null}`，cursor 不透明且校验筛选条件。
- 查询参数只接受列出的筛选项；搜索 `q` trim 后最多 100 字符；时间字段不接受无时区字符串。week 必须合法 ISO `YYYY-Www`，周历省略时用当前周；我的本周/参与统计拒绝 week 参数。
- 创建百业/场次、审批通过、接受邀请、报名/指派要求 `Idempotency-Key`（UUID）；重复显式重试复用原 Key。删除/硬清理后清除关联幂等响应，旧 Key 不能恢复旧业务数据。
- 百业/模板/场次修改带 expected_version；DELETE 场次/模板及移出成员通过 `X-Expected-Version` 传版本（移出使用百业版本）。解散另需 `X-Confirm-Guild-Id`，移出另需 `X-Confirm-Membership-Id`。缺少必要版本/确认返回 400，陈旧版本返回 409 VERSION_CONFLICT。

## 2. 字段与输入模型

字符串长度统一按 UTF-16 代码单元计算（C# string.Length、JavaScript string.length），前后端相同口径；自由文本 trim，允许换行但不接受 HTML。响应始终纯文本展示。枚举 server=official/channel，role=owner/admin/member，slot_role=tank/healer/dps，signup_mode=open/assign。

| 请求模型 | 完整字段与校验 |
|---|---|
| EmailCodeRequest | email 必填，规范化后 <=254，校验邮箱格式；绑定场景 user_id 从 sub 获取 |
| RegisterRequest | email、password、challenge_id、verification_code 必填；password 8..128，不 trim；验证码 6 位数字；nickname 可选 1..32，省略时后端生成不含邮箱的默认昵称 |
| LoginRequest | email、password 必填；密码 1..128，用于验证已有凭证，不套注册最小长度 |
| BindEmailRequest | email、challenge_id、verification_code 必填，用途/邮箱/当前账号必须匹配 |
| UpdateMeRequest | nickname 可选 1..32；default_profile_id 可选 UUID/null，非空必须属于本人；不接受 email/password |
| ProfileCreateRequest | name 必填 1..32；server 必填；power 必填数值 0..99999999.9999，最多 4 位小数；styles 必填 1..20 个唯一有效字典代码；online_slots 可选默认 []、最多 28 个；bio 可选默认空、<=500 |
| ProfilePatchRequest | 上述字段均可选，仅 bio 允许 null（清空）；不能修改 user_id；名字不设全平台唯一，同名使用 ID 区分 |
| OnlineSlot | weekday=1..7，start_minute=0..1439，end_minute=1..1440；start<end，跨午夜拆为两条，完全重复拒绝 |
| GuildCreateRequest | name 必填 1..40；server 必填；intro 可选 <=2000；recruit_requirements 可选 <=1000；recruiting 可选默认 true；新建默认提醒 true/30 分钟 |
| GuildPatchRequest | name、intro、recruit_requirements、recruiting 可选，边界同创建；expected_version 必填；不修改 server/owner/成员身份，改社长走转让接口 |
| ReminderSettingsRequest | reminder_enabled 必填 bool；remind_minutes 必填整数 1..1440；expected_version 必填；关闭仍保留分钟值 |
| ApplicationCreateRequest | message 可选 <=500，默认空；guild_id 从路径获取，申请人从 sub 获取 |
| ApplicationDecisionRequest | decision 必填 approved/rejected；expected_status 必填 pending；handled_by 从 sub 获取 |
| InvitationCreateRequest | type=code/direct 必填；direct 必填 target_user_id，code 禁止该字段；expires_at 可选/null，省略默认当前时间+7天，指定时须在未来且 <=30天；max_uses 仅 code 可选 1..1000，默认 20，direct 固定 1 |
| MemberRoleRequest | role 必填 member/admin；expected_version 必填，指百业版本；仅社长操作，不接受 owner |
| OwnerTransferRequest | target_membership_id 必填、不是本人；previous_owner_role 必填 member/admin；expected_version 必填 |
| LeaveRequest | expected_version、confirm_guild_id 必填；本人当前是社长且未转让时 confirm_dissolve=true 必填，否则禁止 true；确认 ID 必须与路径相同 |
| AccountDeletionRequest | confirm_user_id 必填且等于 sub；confirmation 必填且严格等于 DELETE；随时可执行，不要求已绑定邮箱，不增加验证邮件 |
| TemplateCreateRequest | name 必填 1..80；need_tank/need_healer/need_dps 必填整数 0..10，合计 1..10；default_duration_min 必填整数 1..1440 |
| TemplatePatchRequest | 上述字段可选，合并后容量合法；expected_version 必填；系统模板不能修改 |
| EventCreateRequest | template_id、starts_at、signup_mode 必填；starts_at 必须未来且 <=366天；title 可选 1..80，省略取模板名；duration_min 可选 1..1440；need_tank/healer/dps 可选但修改容量必须三个一起提供，合计 1..10；status 可选 draft/published，默认 published；note 可选 <=2000；reminder_enabled/remind_minutes 可选，后者 1..1440；缺省值继承模板/百业快照 |
| EventPatchRequest | title、starts_at、duration_min、signup_mode、三项容量、note、status、reminder_enabled、remind_minutes 可选；expected_version 必填；template_id 不可改；status 仅 draft→published，不能客户端写 cancelled/finished，空 note 可 null 清除；变更开始时间必须未来，合并后按事务检查容量/冲突 |
| AssignmentCreateRequest | action=signup/assign 必填；profile_id、slot_role 必填；signup 仅本人开放报名，定位满则候补；assign 仅管理员/社长，允许相互指派，满员 409；禁止 user_id 和客户端 status |
| ReadNotificationsRequest | notification_ids 与 all 二选一；IDs 1..100 个唯一 UUID，或 all=true；不允许 all=false/同时填写 |

验证码 TTL 10 分钟、最多验证 5 次，重发至少 60 秒；登录、发送、验证入口另设 IP/账号限流。Resend 供应商已配置；QQ 暂缓。验证码与限流使用当前 AuthRedisStore 实施常量。

## 3. 共享响应模型

下列字段均进入实际 OpenAPI。`?` 表示值可为 null，不表示可任意省略；私有字段仅本人响应允许。普通对象如无特别说明包含 id/created_at/updated_at，汇总对象使用下列明确字段。

| 响应模型 | 字段 |
|---|---|
| AuthResult | access_token、token_type=Bearer、expires_in=900；Refresh Token 仅 Set-Cookie，不在 JSON 中；注册另返回 user_id |
| CsrfResult | request_token；前端存内存并通过 X-CSRF-TOKEN 发送 |
| CodeChallenge | challenge_id、expires_in、resend_after；供应商成功才返回受理 |
| ActionResult | success=true；审批/邀请动作使用对应更新后的资源代替该结构 |
| DeleteResult | deleted=true；退出百业另含 guild_dissolved；不返回已删除对象正文或可恢复历史 |
| Me | user_id、nickname、email?、email_verified_at?、requires_email_binding、default_profile:Profile?、membership:MembershipContext? |
| MembershipContext | membership_id、guild_id、guild_name、role、joined_at、guild_version |
| Profile | id、user_id、name、server、power、styles:string[]、online_slots:OnlineSlot[]、bio、is_default、created_at、updated_at |
| AssignmentWrite | action、profile_id、slot_role 必填；slot_index 可选 1..10，指定座位，须与 slot_role 一致且未被占用（SEAT_TAKEN）；未指定时自动取该定位首个空座，座位满则进入候补（assign 不能候补） |
| ProfileSummary | profile_id、user_id、name、server、power、styles；无邮箱/QQ/简介等额外字段 |
| ProfileOptions | dictionary_version、servers:{code,label}[]、styles:{code,label}[]；只返回启用选项 |
| Player | user_id、nickname、default_profile:ProfileSummary、matching_profiles:ProfileSummary[] |
| PlayerDetail | user_id、nickname、profiles:{ProfileSummary + online_slots + bio}[]；仅散人可查，不返回私有账号信息 |
| GuildSummary | id、name、server、intro、recruit_requirements、recruiting、member_count、version |
| GuildDetail | GuildSummary + public_members:ProfileSummary[]（最多20）、recent_events:{id,title,starts_at,ends_at}[]（最多10）、my_application:Application?；完整内部名单走 members，不返回内部排班 |
| GuildCreated | GuildSummary + owner_membership:MembershipContext |
| Member | membership_id、user_id、nickname、role、joined_at、default_profile:ProfileSummary?、profiles:ProfileSummary[] |
| Application | id、guild_id、guild_name、user_id、message、status=pending/approved/rejected/withdrawn、created_at、handled_at?；管理查询另含 applicant:ProfileSummary?；不展示审核人私有信息 |
| Invitation | id、guild_id、guild_name、type、target_user_id?、expires_at?、max_uses、used_count、status、created_at；创建 code 邀请另返回一次性 code、invite_url |
| InvitationPreview | invitation:Invitation、guild:GuildSummary、inviter_nickname?（仅定向）、can_accept、can_decline、unavailable_reason?；无联系方式/内部名单，非目标账号定向预览返回404 |
| OwnerTransferResult | owner_user_id、previous_owner_role、version、members:{membership_id,role}[] |
| ReminderSettings | reminder_enabled、remind_minutes、version；百业默认与场次独立，修改默认不批量覆盖旧场次 |
| Template | id、guild_id?、name、need_tank、need_healer、need_dps、default_duration_min、version、archived_at? |
| Assignment | id、user_id、membership_id、profile:ProfileSummary、slot_role、status=confirmed/waitlist、created_at、waitlist_position? |
| AssignmentResult | assignment_id、status、waitlist_position?、event_version；不以消息文本推断正式/候补 |
| CancelAssignmentResult | deleted=true、event_version；前端刷新名单和自己的状态 |
| Event | id、guild_id、template_id、template_name、title、starts_at、ends_at、duration_min、signup_mode、status=draft/published/cancelled/finished、note、version、reminder_enabled、remind_minutes、is_locked、capacities:{tank,healer,dps}、confirmed_assignments:Assignment[]、waitlist_assignments:Assignment[]、my_assignment:Assignment?、can_signup、can_cancel、can_manage、disabled_reason? |
| WeekEvents | week_key、week_start、week_end、timezone、server_time、events:Event[] |
| MyWeek | week_key、week_start、week_end、timezone、server_time、items:{event:EventSummary,assignment:Assignment}[]；EventSummary 为 id/guild_id/title/starts_at/ends_at/status/version/can_cancel，无全队名单 |
| Participation | basis=confirmed_assignments、week_key、week_start、week_end、timezone、server_time、cumulative_cutoff=week_end、includes_future_in_current_week=true、items:{membership_id,user_id,nickname,weekly_count,cumulative_count,rank}[]、unassigned_user_ids:UUID[] |
| Notification | id、type、title、body、created_at、read_at?、target:{kind,guild_id?,event_id?,invitation_id?,application_id?}；kind=raid_event/guild/invitation/application，所需ID按kind校验，只映射已知内部路由，正文纯文本 |
| UnreadCount | unread_count，整数>=0 |
| ReadResult | updated_count、unread_count |

GuildDetail 的成员/近期摘要是有限预览；成员 GET 支持分页。Event 正式名额<=10，候补单场最多100个账号，超限报名返回409 WAITLIST_LIMIT_REACHED；Member 单账号角色最多10个，新增超限返回409 PROFILE_LIMIT_REACHED。参与统计按百业当前成员聚合，使用 page/page_size 分页 items，响应补 page/page_size/total，unassigned_user_ids 只包含当前页的未排班成员；查询可用 unassigned_only=true 筛出全部未排班成员并逐页读取，不无限返回全量历史。

## 4. HTTP 操作映射

参数为空表示无请求体，不表示免认证。创建/修改/查询分别使用上述完整模型；如额外筛选未列出，接口不接受。

### 4.5 通知

| GET /notifications/unread-count | 无 | UnreadCount |
| POST /notifications/read | ReadNotificationsRequest | ReadResult |

他人通知ID返回404，不部分更新一批中合法IDs而隐瞒非法IDs；请求内全部合法后再事务标记。all=true 按请求时已存在的本人记录处理，不误标之后新增记录。

## 5. 统一业务错误

| HTTP | code | details/前端行为 |
|---|---|---|
| 400 | VALIDATION_FAILED | fields:[{field,message}]；缺少确认/版本也返回字段信息 |
| 400 | INVALID_WEEK / VERIFICATION_CODE_INVALID | 周编号错误或验证码错误，不展示内部凭证 |
| 401 | INVALID_CREDENTIALS / TOKEN_EXPIRED / REFRESH_TOKEN_INVALID / ACCOUNT_NOT_FOUND | 登录错误统一；业务请求可刷新一次，认证自身不递归刷新，已注销账号清理登录态 |
| 403 | EMAIL_BINDING_REQUIRED / ACCOUNT_DISABLED / PERMISSION_DENIED | 转绑定或提示拒绝；注销后账号不存在返回401 |
| 404 | RESOURCE_NOT_FOUND | 删除或无权访问资源不泄露详情；清理对应缓存 |
| 409 | ALREADY_IN_GUILD / ALREADY_APPLIED / ALREADY_ASSIGNED | 当前业务状态冲突，刷新列表/归属 |
| 409 | ACCOUNT_TIME_CONFLICT | conflicting_event_id；仅返回本人或操作者有权读取的事件标识 |
| 409 | CAPACITY_CONFLICT / WAITLIST_LIMIT_REACHED | 定位满或候补达到限制，slot_role |
| 409 | EVENT_STARTED / VERSION_CONFLICT / APPLICATION_ALREADY_HANDLED | 版本冲突返回current_version；处理竞态返回最新可见status |
| 409 | INVITATION_EXPIRED / INVITATION_REVOKED / INVITATION_EXHAUSTED / INVITATION_ALREADY_HANDLED | 刷新预览，不继续重试加入 |
| 409 | EMAIL_ALREADY_IN_USE / EMAIL_ALREADY_BOUND / PROFILE_IN_USE / PROFILE_LIMIT_REACHED | 对应字段/引用场次；不暴露他人账号 |
| 409 | IDEMPOTENCY_KEY_REUSED | 同Key不同请求，客户端不能自动更换Key掩盖问题 |
| 429 | RATE_LIMITED | Retry-After，前端冷却 |
| 503 | AUTH_STATE_UNAVAILABLE / REFRESH_STORE_UNAVAILABLE / VERIFICATION_EMAIL_UNAVAILABLE / DICTIONARY_NOT_READY | 可重试，供应商失败不宣称注册完成，字典待用户初始化 |

接受/报名等非幂等动作网络超时不自动创建新请求；显式重试复用原 Key。硬删除后返回404/401按当前状态处理，不借缓存重现被删除响应。

## 6. SignalR 与数据初始化

- NotificationHub：JwtBearer + VerifiedEmailRequired，账号ID从验证后的sub获取，只向本人连接推送。
- `notifications.changed` 载荷 `{reason:"created"|"read"|"deleted"}`；created/read 刷新通知查询，deleted 另重读 /me 和当前百业上下文；不用实时提示累加未读数。
- 先提交数据库再提示，失败不回滚；首次连接/重连/聚焦补查，断线每30秒降级查询。注销后不再向已删除账号投递，旧连接不能绕过账号存在性校验。
- 认证到期关闭旧连接，统一刷新后重连；浏览器 WebSocket/SSE 的 access_token 查询参数只允许Hub路径，HTTPS/WSS，代理/应用/追踪均脱敏。完整生命周期按通知方案6.1。
- PostgreSQL 增加 `profile_style_options(code PK,label,sort_order,enabled,updated_at)`；服务器选项为固定official/channel。正式流派字典和系统副本模板由用户初始化，不把前端演示数据写成生产初始值。dictionary_version由字典更新状态计算，客户端根据版本刷新。
- Resend 凭证已配置到被忽略的本地 appsettings，生产使用部署配置注入；QQ 暂缓。测试邮件替身仅在测试工程注册，生产无模拟认证回退。
