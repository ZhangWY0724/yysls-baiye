## 前端接入

邮箱登录/注册、个人设置和角色、本人申请/邀请、百业列表/详情/设置/成员协作、散人筛选、模板、周历与场次详情、我的本周、通知中心均使用真实 API。邀请预览为独立页面；注销与社长退会/解散都有明确确认。

Access Token 仅存内存，刷新会话为 HttpOnly Cookie；刷新请求串行并使用 Web Locks 协调标签页。退出通过 BroadcastChannel 同步，迟到响应校验会话版本。网络中断后同一幂等操作重试复用标识。服务端查询使用轻量 useQuery，写成功或版本冲突后重新获取；未引入 TanStack Query。

通知使用 SignalR Long Polling 适配当前 Next.js 转发；首次失败重试、JWT 到期刷新重连，断线或连接失败时每 30 秒补查，可见性与重新聚焦触发检查。通知事件只提示变化，实际正文与未读数从 REST 读取。

## 本期实现取舍

- 单 API 工程，EF Core 直接访问数据，不增加通用仓储、消息总线或微服务。
- 业务写入和通知任务共享 PostgreSQL 事务级 advisory lock，确保容量、跨角色冲突和删除一致性。本期写操作整体串行，规模增长后需要实测并细化锁。
- 业务通知在业务事务内直接写入；ReminderService 每 15 秒扫描到期场次写入开打提醒，改时和删除后从实时数据重新判定。SignalR 提示失败不回滚业务。（2026-10-14 起取代 Outbox 与 Quartz。）
- 候补保存并使用报名时所选角色；更换角色/定位须取消后重新报名，不在递补时静默切换默认角色。
- 注销提交后按账号 Redis 会话索引撤销所有会话；Redis 暂不可用时，数据库账号校验仍立即拒绝旧 Token，残留技术键按最长 7 天 TTL 到期。目前没有额外持久化技术清理队列。
