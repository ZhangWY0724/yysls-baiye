## 请提供的基础数据

| 数据 | 必要字段 | 约束 |
|---|---|---|
| 流派 | code、label、sort_order、enabled | code 全局唯一、最多 64 字符；label 最多 64 字符；enabled 默认 true |
| 系统副本模板 | name、need_tank、need_healer、need_dps、default_duration_min | 名称 1–80 字符；定位人数均为 0–10，合计 1–10；时长 1–1440 分钟 |

可以发文字表格或 JSON，格式如下，填入实际内容即可：

```json
{
  "styles": [
    { "code": "正式流派代码", "label": "正式显示名称", "sort_order": 1, "enabled": true }
  ],
  "templates": [
    { "name": "正式副本名称", "need_tank": 1, "need_healer": 2, "need_dps": 7, "default_duration_min": 60 }
  ]
}
```

以上只说明格式，不是已确认的正式数据，不会自动导入。收到内容后先校验唯一性和人数，再生成具体初始化 SQL。也可以由你直接初始化数据库。

流派写入 `profile_style_options`，同时填写 `updated_at`。系统模板写入 `dungeon_templates`，`guild_id` 和 `created_by` 为 NULL，`archived_at` 为 NULL，`version=1`，填写 UUID、created_at/updated_at 及上述业务字段。系统模板只读，社长/管理员可另外创建本百业模板。

区服本期固定为 `official=官服`、`channel=渠道服`，无需初始化。平台不提供超级管理员账号，百业社长由创建百业的真实账号产生，不需要演示账号或默认密码。

流派和系统模板已就绪，可通过真实注册、角色保存、创建百业及排班流程继续验收。有权限成员可另行创建百业模板供排班使用。

## 本地与生产配置

开发配置为 `apps/api/appsettings.Local.json`，已按用户要求填写服务器依赖与 Resend，文件被忽略且不会复制到发布目录。请勿把它复制进受版本控制的 appsettings。生产通过配置注入填写：

- `ConnectionStrings:Postgres`、`ConnectionStrings:Redis`。
- `Auth:SigningKey`、`Auth:Issuer`、`Auth:Audience`。
- `Email:ResendApiKey`、`Email:From`；发件域名为已验证的 io724.fun。
- `Cors:AllowedOrigins`：明确的前端完整来源，例如 https://你的前端域名；内部 API 代理和前端来源不一致时仍须配置。
- `AllowedHosts`、`Proxy:KnownProxies` 和持久化 `DataProtection:KeysPath`。
- Next.js 的 `API_INTERNAL_URL` 指向内部 API 地址。

邮件只通过注册验证码接口发送。登录、业务通知、退会和注销不调用邮件服务。
