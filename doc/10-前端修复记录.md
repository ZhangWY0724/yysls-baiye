## 本轮变更

- 登录成功通知本标签页清理旧账号资料、未读数和连接；重新加载当前账号。CSRF、刷新与业务响应校验会话代次，拒绝账号切换后的迟到结果。共享布局继续跨业务路由保持会话，普通页面切换不重新恢复登录。
- GET 合并按会话、写入失效代次和路径区分；写成功后的刷新不会复用写入前的请求。共享 GET 按订阅取消，最后一个订阅离开后取消网络，兼容 Strict Mode effect 清理和重建。
- 请求统一 20 秒超时，规范网络、非 JSON/HTML 代理错误；保留幂等请求在网络故障后的标识。字典缓存 5 分钟，账号切换清空，普通刷新不会清空字典。
- useQuery 区分首次错误和后台刷新错误；已有内容刷新失败显示可重试提示，保留表单。useAction 使用同步引用防止同一事件循环重复提交。
- 通知变化 200 毫秒合并，普通通知不刷新 /me，删除事件才同步账号所属百业信息；通知页挂载不额外执行 reload，操作后避免本地重复刷新。初次连接使用已有 Token，关闭后重试会检查刷新令牌，临时故障安排继续重试。
- 周历、打开的场次详情及我的本周响应通知变化；详情与周历一起定时补查。副本模板按打开面板/创建表单加载；百业、模板和指派成员搜索防抖 300 毫秒。
- 移除后置 select 背景/内边距覆盖，保留下拉箭头与 42px 高度；补齐 Card 直接子 input 样式及详情关闭按钮基础样式。
